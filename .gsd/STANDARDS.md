## Summary of Core Standards

### 1. Architecture: Clean Architecture + DDD
- Every module must maintain strict isolation: `domain/` (pure business logic), `infrastructure/` (SQLAlchemy 2.0 models & repos), `application/` (CQRS commands & handlers).
- Zero external framework imports in `domain/`.

### 2. Timestamps & Timezones
- Always import from `app.core.clock`.
- Persistence: `now_naive_ist()`.
- Input parsing: `to_naive_ist(dt)`.
- Never use raw `datetime.now()` or `datetime.utcnow()`.

### 3. Dependency Injection
- Register in `app/modules/configurator.py`.
- Resolve in routes using `GetHandler.<module>_handler(request)` from `app/modules/dependencies.py`.

### 4. API Response Formats
- Lists: `{status, code, message, items, limit, offset, total, pages, next_page, has_more}`.
- Single: `{status, code, message, data}`.

### 5. Performance
- Use `__slots__ = (...)` on all handlers.
- Use `@dataclass(slots=True, kw_only=True)` on entities, DTOs, and commands.
- Use `ORJSONResponse` / `jsonable_encoder` for fast response serialization.
