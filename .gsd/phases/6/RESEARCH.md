# Phase 6: Formula Rate-Chart Excel Exchange — Research & Architecture

## Problem Space

In dairy operations, milk pricing is calculated in two primary modes:
1. **Prodata (Pro-rata slab ranges):** Exact FAT/SNF ranges with assigned per-kg rates and deduction cutoffs (implemented in Phase 4).
2. **Formula-Based Rate Calculation:** Milk value is mathematically determined using standard benchmark milk parameters:
   $$\text{Rate} = \left(\frac{\text{Std Rate} \times \text{FAT Ratio} \times \text{FAT}}{\text{Std FAT} \times 100}\right) + \left(\frac{\text{Std Rate} \times \text{SNF Ratio} \times \text{SNF}}{\text{Std SNF} \times 100}\right)$$

Currently, users can configure formula parameters in the web UI, but there is no capability to:
- Export the formula configuration and its resulting calculated pricing matrix into Excel.
- Import formula parameters from an Excel spreadsheet to update an existing chart or create a new Formula chart.

## Codebase Patterns & Reuse

Quickyee's Data Exchange engine (Phases 1–5) provides:
1. **Engine Core:** Streaming `XlsxSheetWriter` and `XlsxSheetReader`, `ExchangeWorker`, `ExchangeSupervisor`, resumable chunked uploads, and disk/memory bounds.
2. **Rate Chart Scope:** `RateChartScope` in `app/modules/dataexchange/infrastructure/ratechart_scope.py` provides visibility (`Hierarchy.shared_visible`), modifiability (`Hierarchy.shared_modifiable`), and chart creation quota checks.
3. **Database Entities:**
   - `RateChartModel`: `chart_type = RateChartType.FORMULA` (0)
   - `RateFormulaConfigModel`: Holds COW and BUFFALO standard FAT, SNF, Rate, and FAT% / SNF% contributions.
4. **Resolution Algorithm:** `RateChartRepository.resolve_formula_rate` in `app/modules/ratechart/infrastructure/repository.py`.

## Excel Sheet Design: Formula Rate Chart

### Sheet 1: `Formula Config` (Master Configuration)
| Column | Key | Type | Constraints | Example |
|---|---|---|---|---|
| Animal / Milk Type | `animal_type` | ENUM | COW, BUFFALO | COW |
| Standard FAT (%) | `standard_fat` | FLOAT | > 0, ≤ 20.0 | 4.0 |
| Standard SNF (%) | `standard_snf` | FLOAT | > 0, ≤ 20.0 | 8.5 |
| Standard Rate (₹/L) | `standard_rate` | FLOAT | > 0 | 35.00 |
| FAT Contribution (%) | `fat_percentage` | FLOAT | 0.0 to 100.0 | 60.0 |
| SNF Contribution (%) | `snf_percentage` | FLOAT | 0.0 to 100.0 | 40.0 |

**Validation Invariants:**
- `fat_percentage + snf_percentage == 100.0`
- `standard_fat > 0`, `standard_snf > 0`, `standard_rate > 0`
- Two rows supported: COW and BUFFALO.

### Sheet 2: `Pricing Matrix (Preview)` (Export Only)
Generated by the export processor to give dairy managers a complete 2D rate table:
- Rows: FAT from 3.0% to 10.0% (step 0.1)
- Columns: SNF from 7.5% to 10.5% (step 0.1)
- Cell values: ₹/Liter calculated using the exact formula.
