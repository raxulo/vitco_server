## Architectural Conventions

### 1. Clean Architecture Layer Isolation
- **Domain Layer (`domain/`)**: Pure Python dataclasses and business logic. Zero dependencies on web frameworks or databases.
- **Infrastructure Layer (`infrastructure/`)**: SQLAlchemy declarative models extending `Base`, `UUIDMixin`, `AuditMixin`, `SoftDeleteMixin`.
- **Application Layer (`application/`)**: Command Query Responsibility Segregation (CQRS) handlers.
- **Presentation Layer (`api/v1/` & `web/`)**: FastAPI routes with standard response wrappers.

### 2. Time & Clock Standards (`app.core.clock`)
- Indian Standard Time (IST / `Asia/Kolkata`) is the official timezone.
- Database timestamps use `now_naive_ist()` to prevent timezone offset mismatch during SQL string comparisons.
- Input timestamps are sanitized via `to_naive_ist()`.

### 3. Response Envelope Convention
- **List Queries**:
  `{ status: bool, code: int, message: str, items: list, limit: int, offset: int, total: int, pages: int, next_page: int|null, has_more: bool }`
- **Single Queries**:
  `{ status: bool, code: int, message: str, data: object }`

### 4. Dependency Injection (IoC)
- `ServiceContainer` registers all repositories and handlers in `app/modules/configurator.py`.
- Exposed to FastAPI endpoints through static helpers in `app/modules/dependencies.py` (`GetHandler.<handler_name>(request)`).
